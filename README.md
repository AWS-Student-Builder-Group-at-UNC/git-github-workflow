## 🚦 Cómo usar este repo

1. Cloná el repo o hacé fork si vas a subir tus soluciones a tu propia cuenta.
2. Recorré las lecciones **en orden** — cada una asume lo aprendido en la anterior (ver Prerrequisitos dentro de cada `README.md`).
3. En cada lección: leé el `README.md` → resolvé `practica.md` **antes** de mirar `solucion.md`.
4. Al terminar las 3 lecciones, encarás `04-integrador/` como cierre del tema.
