# Cómo contribuir

Este repo es parte de la biblioteca de aprendizaje del AWS Student Group UNC.

## Antes de contribuir
- Cada lección sigue la estructura fija: `README.md`, `practica.md`, `solucion.md`.
- No se agregan más de 1 práctica por lección (ver criterio pedagógico del área).
- El TP integrador va únicamente en la carpeta `0X-integrador`.

## Estilo de contenido
- Explicá siempre el "por qué", no solo el "cómo".
- Código comentado en español, comandos explicados línea por línea si son nuevos.
- Incluí sección de limpieza de recursos si la lección usa servicios de AWS.

## Proceso
1. Fork o rama nueva (`leccion/nombre-tema`).
2. Seguí el template de la carpeta `01-leccion-nombre` como referencia de formato.
3. Pull Request con descripción breve de qué agrega/corrige.
